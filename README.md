# Análise de Indicadores Socioeconômicos

## Sobre o projeto

Este projeto foi desenvolvido no âmbito do Projeto Integrador do curso de Ciência de Dados da FATEC.

O estudo tem como objetivo analisar indicadores socioeconômicos de municípios da região oeste da Grande São Paulo, utilizando dados do ano de 2022 e técnicas de tratamento, análise e visualização de dados.

## Municípios analisados

- Santana de Parnaíba
- Osasco
- Barueri
- Jandira
- Itapevi
- Carapicuíba
- Pirapora do Bom Jesus

## Objetivo

Analisar os indicadores selecionados e identificar padrões, diferenças e tendências entre os municípios estudados, utilizando recursos de análise e visualização de dados.

## Metodologia

O desenvolvimento do projeto segue etapas inspiradas na metodologia CRISP-DM:

1. Entendimento do problema
2. Entendimento dos dados
3. Preparação dos dados
4. Análise
5. Visualização dos resultados
6. Avaliação
